# commit 規則

今晚只本機 commit、不 push 不 pull；只 commit 彙總與沉澱下來的東西。

- 交接書沒寫就不 commit。
- 訊息英文，結尾照抄交接書給的署名行（Co-Authored-By、Claude-Session）。
- 只 `git add` 自己的檔，不 `git add -A`；別人的未追蹤檔不碰。
- 族群、各代候選、原始大輸出放 gitignore 夾或 scratchpad；不 commit 大檔。
- 今晚不 push（使用者 11-09 23:4x：「今晚都不要push吧……我醒來後再push。」），覆蓋 user.md「可隨意 push」。
- 改條文時舊句直接刪，不留刪除線。
