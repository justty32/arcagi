# 程式與文件入口

程式導航看 code-map，環境指令看 dev-env，文件結構看 INDEX。

- 程式導航：`wf/workflows/common/code-map.md`（tasks、solvers、runtime…）；輪次模組 `wf/workflows/common/code-map/輪次模組.md`。
- 慣例：`wf/workflows/common/conventions.md`。
- 環境：`wf/workflows/dev-env.md`。常用：`uv run pytest -q`、`uv run arcagi --help`、`uv run arcagi eval --split evaluation --solver <s> --output <f>`。
- 原生碼：`native/`（GPU 搜尋 `native/bin/gpusearch`、特徵工具 `native/tools/`）。
- 活樹：`~/code/playground-arc1/ws/`。
- 文件結構：`wf/INDEX.md`；依意圖派發 `wf/WORKFLOWS.md`；分層原則 `wf/STRUCTURE.md`。
- 支線（S1 C++ 等）：`notes/rounds/支線.md`。
