# 使用者習慣要點

講人話、睡時不問改放看板、晨報先結論、「不如…」是討論；完整版在 user.md 與 aos 速查。

- 睡著時不問、不停線：要他裁的放看板「待你裁」附預設與後果，先照預設做。
- 晨報：①一兩句結論 ②代定清單附翻案處 ③要他裁的 ≤5 題附推薦；白話、細節折疊。
- 講人話：完整句、一段一重點、術語用比喻帶過、不讓他查編號表。
- 「不如…」「幫我想想」是討論，等「開工」才動手。
- 大方向是他的；你挖邊緣狀況、做原型給他試。
- 問「要不要」時附可執行判準（門檻數字）與後果。
- 外出時大小決策先代定、記代定清單。
- 長期記憶寫進 `wf/`，不寫 agent 自動記憶。

出處：`wf/workflows/common/user.md`、`wf/workflows/common/user-aos習慣速查.md`（衝突以 user.md 為準）。
