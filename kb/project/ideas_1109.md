# 使用者 11-09 夜建議 1～8

演化對象是整棵 aos 樹、分層改進、成本可變、積木不分大小；原文在使用者方向。

原文：`notes/rounds/總表/使用者方向.md`「11-09 夜建議」。一句話摘要：

1. 遺傳搜尋用在 aos 樹上：樹序列化成 json／janet／lua／python 再突變、交配。
2. 純解題的 GPU 長跑是空轉；要留每題搜尋剖面（題目特性）給後續訓練。
3. 樹可嵌套（A-B-C 是 D-E-F 裡的 D），配節點池、分錢。
4. 修正 3：主模式是分層式改進，上層把改進責任分給節點，節點再改自己的子樹。
5. 成本：符號回歸花時間、agent 參與花 token，同一本帳。
6. 成本是任意 JSON，agent 可自創、細化、統括、只取部分 key。
7. 節點池膨脹快，只 push 沉澱下來的；程式碼演化用 Janet（lisp）。
8. aos 樹本身也是積木，節點也是積木。
