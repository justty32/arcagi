### 2. codex 叫 gpt sol

**一律明帶 `-m` 和 `-s`。** 家機 ~/.codex/config.toml 的預設是 `model = "gpt-6.1-terra"`、`sandbox_mode = "danger-full-access"`，不帶就是 terra 加全權限。

```

```
codex exec -m gpt-6.1-sol -s workspace-write [-c sandbox_workspace_write.network_access=true] \
  -C /home/lorkhan/code/playground-arc1 [--add-dir /home/lorkhan/repo/arcagi/<子夾>] \

### 3. fable 與 Argon

**fable**：
- Claude Code 子 agent 用 `Agent(..., model="fable")`。aos 這邊 Agent 工具的 model 可選 sonnet／opus／haiku／fable。
- CLI 用 `--model fable`。alt 帳號的寫法（11-08 alt-fable 用過）：
  `CLAUDE_CONFIG_DIR=~/.claude-alt nice -n 10 claude -p "$(cat 提示檔)" --model fable --allowedTools Read Glob Grep > out.md`
- 規矩：fable 只讀備好的料、不廣讀 repo，提示要自足（出處 aos-teams.md、alt-fable/01-題單.md）。

**Argon**：11-08 那條仍有效，以後來的 05 版為準（出處 /home/lorkhan/repo/simple_tools/aos/wf/workflows/dispatch/aos-teams/05-同機session與Argon.md）：
```
cd /tmp && agy -p "<要審的全文＋問題；明講不要用工具、直接依文字作答>" --model "Gemini 4 Argon (High)" --mode plan --print-timeout 840s > 02b-Argon審.md
```
- 今晚 `agy models` 列得出 `Gemini 4 Argon (High)`（id `gemini-4-argon-high`），型號名沒變。
- headless 模式下它一要讀檔或跑指令，就會因沒法問權限而空手結束，所以全文要貼進提示，不加 `--dangerously-skip-permissions`。
- 提示超過約 128 KB 時，把提示寫成檔、放進 `--add-dir` 的夾，叫它用讀檔工具讀。
- 輸出出現 "Authentication required"（不分大小寫）就重試。
- `--effort` 對 argon 無效，強度靠型號名裡的 High。
- 慣例是寄 PROGRESS 給 aos、由 aos 頂層統一叫（你們 總表/規矩.md 也這樣寫）；你們自己照上面的指令叫也行。

**額度怎麼判斷**：查不到方法。agy 1.5.3 沒有查剩餘額度的子指令，wf 也沒記判斷法。只有兩條：
- 11-08 定的「額度少，每輪一兩次、挑最關鍵的稿」
- 使用者 11-08 晚說過「argon那邊額度也一堆」（alt-fable/README.md）
