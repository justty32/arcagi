## 1. 成本帳 `cost.jsonl`（開放 JSON，回應建議 5、6）

每列：`{"schema":"t2-cost/1","epoch":t,"who":"hammer","cost":{...},"src":"epochs/t/curve.csv"}`。

舊欄映射（curve.csv → 點分 key）：`evals_body→evals.body`、`evals_shadow→evals.shadow`、`evals_meta→evals.meta`、`evals_foundry→evals.foundry`、`llm_calls→llm.calls`、`wall_s→wall_s`。`logcost_L`、`lib_bits` 是狀態不是花費，不進 cost。`who` 這輪只有 `hammer`（離線拆不出節點級花費，不猜）。

**schema 規則**（`cost.validate(cost) -> list[str]`，空＝合法）：
1. key 符合 `^[a-z0-9_]+(\.[a-z0-9_]+)*$`；值必須是有限 `int|float` 且 ≥0（bool 不算數）。
2. **細化／統括互斥**：同一列不可同時有 `a` 與 `a.b`（祖先與子孫並存＝重複計）。要統括用 `rollup(cost, depth)` 產新 dict，不在原列混放。
3. 任意新 key 合法（如 `gpu.sec`、`agent.ideas.tokens`）；無 rate 的 key 計 0 但保留在列裡。

函式：`price(cost, rates, keys=None) -> float`＝Σ rate.get(k,0)×cost[k]，`keys` 給定時只算該子集（**前綴匹配**：`keys=["evals"]` 算所有 `evals.*`）。`rollup(cost, depth)`：把 key 截到前 depth 段加總。rates 本身也走 validate 規則 1（值可為 0）。

## 2. 頂層金額

`eff_t`＝`auc_L(1..t) / (Σ_{e=0..t} evals_e / 1e6)`（與 `think1_meter` 同式、不取整；t=0 時 auc 空＝0）。頂層 `amount_t = eff_t − eff_{t−1}`，t=1..8。Σ_t amount_t ＝ eff_8，須與 `think1_meter` 的 `eff` 差 ≤ 1e-4（後者取 4 位）。

## 3. 兩層分功勞 `credit.jsonl`

常數（寫在 `credit.py` 的 `SPLIT`，並登錄到守門二 thresholds 若守門要求）：root_keep=0.2、node_keep=0.2、op_star=0.7、op_base=0.1（後三者為節點金額的比例，和=1）。

**op→節點**：`comb`、`decomp`→`nodes/solve`；`gate`→`nodes/gate`；`route`→`nodes/route`；其他 4 節點（foundry、grow、judge、stall）不持 op。

**epoch t 的 live op**：comb＝`epochs/t/blocks.json` 的 name 加前綴 `comb_`；非 comb＝`born.epoch ≤ t` 且 ops.jsonl 終態 `status=="live"`（離線近似，記入限制）。

**單輪新解題**：`set=="L16"` 且 `train_ok` 的 task id，在 t 有、在 t−1 沒有；每題的程式用 `think1_audit.block_refs` 同法取 `blk` 名 → `comb_<name>`；無 blk 的題計入「未歸屬」。

**第一層**（root→nodes）：root 自留 `0.2·A`；`0.8·A` 依 `nodes/*/_metainfo.json` 的 `weight`（status=active）比例分給節點。守恆一：`keep_root + Σ_node = A`。
**第二層**（node→ops，只對持 op 的節點）：節點金額 N：
- 該節點當輪無 live op → 全留（keep=N）。
- 否則 keep=`0.2·N`；`0.1·N` 平分給所有 live op（底薪／房租）；`0.7·N` 按「歸屬到該 op 的新解題數」比例分；若該節點當輪無任何歸屬新解題，這 0.7 也平分給 live op。守恆二：`keep_node + Σ_op = N`。
負 A 照同式（金額為負＝責任）。浮點：每組最後一個收受者拿餘數，使守恆殘差數學上為 0。

列格式：`{"schema":"t2-credit/1","epoch":t,"layer":1|2,"from":"root"|"nodes/x","to":"nodes/x"|"ops/<id>"|"keep","amount":float,"why":{"share":"keep|weight|base|star","new_solves":[...],"d_eff":A}}`。`keep` 列也寫出（讓守恆可只靠檔案驗）。另輸出 `by_subtree.json`：`{"nodes/solve": Σ_t 第一層到該節點金額, ...}` 給塊 4。

## 4. 體檢 `health.json`

用 importlib 載入唯讀 `scripts/think1_audit.py`（不改它）跑 `scorecard(root, 8, epochs)`，按 §3 的 op→節點映射彙總 `verdict` 計數。格式：`{"schema":"t2-health/1","epoch":8,"nodes":{"solve":{"ok":bool,"verdicts":{...},"n_ops":n},...}}`，7 節點全列；不持 op 的節點 `ok=true, verdicts={}, n_ops=0, note:"no ops"`。`ok`＝無 `retire-candidate`／`dormant-stale`。另寫 `retire_suggest.jsonl`（只建議，不動樹）。
