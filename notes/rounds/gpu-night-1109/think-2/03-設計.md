## 3. 基因體邊界 `hammer-v1`（寫死在 boundary.py）

## 4. 檔案格式

**`tree.json`**（用 `formats.write_json` 寫）：
```
{"schema":"aos-tree/1","name":"hammer","boundary_profile":"hammer-v1",
 "exported_from":"<abs path>","at":"<iso>","dedup":true,
 "genome_sha":"<sha1 hex 前 12：canonical({"defs":…,"tree":…})>",
 "defs":{"<sha12>":<子樹>},
 "tree":{"_metainfo.json":{…},"frozen.json":{…},"ops.jsonl":[{…定義欄…},…],
         "nodes":{"<name>":{"_metainfo.json":{…}},…},
         "truth":{"train":{"taskset.json":{…}},"cal":{"ids.json":{…}}},
         "ctl":{"$file":…},"_view.sh":{"$file":…},"README.md":{"$file":…}},
 "stats":{"files":n,"bytes":n,"refs":n,"defs":n,"skipped":[…]}}
```
- canonical＝`json.dumps(x, sort_keys=True, separators=(",",":"), ensure_ascii=False)`；sha12＝`sha1(canonical.encode()).hexdigest()[:12]`。
- `genome_sha` 只算 `defs`＋`tree`，不含 `at`、`exported_from`、`stats`。
- `truth` 不另加 `$sealed` 標記（02 的寫法取消；封存靠第 6 節 P3 核 sha）。

**去重 `refs.py`**（D13，bottom-up）：
1. post-order 走 `tree`：先處理子節點，再處理父節點。
2. 每個 object／array 子樹（已把子節點換成 `$ref` 之後）算 canonical；canonical 長度 ≥64 bytes 且在整棵（同樣 bottom-up 後）出現 ≥2 次 → 搬進 `defs[sha12]`，原位換 `{"$ref":"#/defs/<sha12>"}`。
3. 做法建議：先一趟 post-order 統計「子樹已替換後的 canonical」出現次數，再一趟 post-order 替換；兩趟用同一個函數算 canonical，保證唯一。
4. 不去重的位置：`tree` 第一層的值本身、`$file` 存根。
5. `$ref` 只准 `#/defs/<sha12>`；展開時遇到別的形式直接報錯。展開要遞迴（defs 內可再含 `$ref`）。
6. `--dedup off`：`defs={}`，不替換。

**`state.json`**（`formats.write_json`）：`{"schema":"aos-tree-state/1","ops":{"<id>":{evidence,ttl,env_hash,blamed_by,tried_env_hashes}}}`。

**import 規則**：
- 目標夾必須不存在或為空，否則報錯退出（不刪、不覆蓋）。
- 先展開 `$ref`；JSON 檔用 `formats.write_json` 寫回原相對路徑；`ops.jsonl` 照陣列順序，每列＝定義欄＋狀態欄（有側車取側車；無側車取 `formats.new_op(...)` 產生的同名欄預設值），用 `formats.write_jsonl` 寫。
- 依第 3 節投影規則寫 `ops/<id>/_metainfo.json`。
- 存根：從 `files/<sha1>` 複製位元組，寫前核 sha1 與 bytes，`chmod` 成 `mode`。

**`diff.json`**：`{"a":…,"b":…,"n_diff":n,"diffs":[{"path":"/tree/ops.jsonl/3/status","a":…,"b":…}]}`；兩邊都先展開 `$ref` 再比 `tree`；不比 `at`、`exported_from`、`stats`、`dedup`。`--ignore-op-order` 時 `ops.jsonl` 先依 id 排序再比（塊 1 驗收不用這個旗）。

## 5. CLI

```
python -m arcagi.treegen.cli export    <tree_root> --out <dir> [--dedup on|off] [--tree-name tree.json]
python -m arcagi.treegen.cli import    <tree.json> --dest <dir> [--state <state.json>] [--files <dir>]
python -m arcagi.treegen.cli diff      <a.json> <b.json> [--ignore-op-order] [--out diff.json]
python -m arcagi.treegen.cli roundtrip <tree_root> --out <dir> --accept <accept.json>
```

`roundtrip` 依序做（`<out>` 須不存在或為空）：
1. 對 `<tree_root>` 的基因體檔＋`ops/*/_metainfo.json` 記 `{相對路徑: (sha1, mtime_ns)}` → before。
2. export（dedup on）→ `<out>/tree.json`、`state.json`、`files/`；計時 t_export。
3. export（dedup off）→ `<out>/tree.nodedup.json`。
4. import（帶 state）→ `<out>/tree2/`；計時 t_import。
5. export `<out>/tree2` → `<out>/tree2.json`、`<out>/tree2.state.json`。
6. diff `tree.json` vs `tree2.json` → `<out>/diff.json`；diff `tree.json` vs `tree.nodedup.json`；比 `state.json` 與 `tree2.state.json` 的 `ops`。
7. import（不帶 state）→ `<out>/tree2_nostate/`，再 export → `<out>/tree2_nostate.json`；diff 對 `tree.json`。
8. 位元組：第 1 步那批檔逐一比 `<tree_root>` 與 `<out>/tree2/` 的 sha1。
9. `check_root(<tree_root>)` 與 `check_root(<out>/tree2)` 的錯誤數。
10. 用 `formats.ids_sha` 算 `truth/cal/ids.json` 的 H8、H24，對 `frozen.json` 的 `holdout.H8.sha`、`holdout.H24.sha`；同時對 `tree2/` 再算一次。
11. 再記一次 `<tree_root>` 的 (sha1, mtime_ns) → after。
12. 寫 `--accept`。

## 6. 驗收：`reports/think2-1109/rt/accept.json`（就這 3 條）

```
{"schema":"think2-rt-accept/1","src":"…/ws/hammer","out":"…/ws/evo/rt/hammer","at":"<iso>",
 "checks":{
  "P1_content":{"pass":…,"n_diff":0,"n_diff_dedup_off":0,"n_diff_nostate":0,
                "state_equal":true,"genome_sha_equal":true},
  "P2_bytes":{"pass":…,"mode":"bytes","files_compared":n,"files_differ":[],
              "check_root_errors_src":0,"check_root_errors_tree2":0},
  "P3_seal_speed":{"pass":…,"H8":{"calc":"…","frozen":"…","tree2":"…"},"H24":{…},
                   "wall_s":t_export+t_import,"live_untouched":true}},
 "stats":{…tree.json 的 stats…},"pass":P1&&P2&&P3}
```

- **P1 內容**：`n_diff==0`、`n_diff_dedup_off==0`、`n_diff_nostate==0`（無側車時定義欄仍相同；狀態欄不在 tree.json 裡，自然不比）、`state_equal`、`genome_sha_equal` 全真。
- **P2 位元組**（D10）：帶側車的 `tree2/` 對原樹，基因體檔＋`ops/*/_metainfo.json` 全部 sha1 相同（`files_differ` 空），且兩邊 `check_root` 錯誤數相同（原樹現況 0）。
- **P3 封存與速度**：H8／H24 的 `calc`＝`frozen`＝`tree2` 三者相同；`wall_s ≤ 5`；`live_untouched`（before＝after，sha1 與 mtime 都沒變）。
- **D10 退路**：工具**不自行降級**，`mode` 固定 `"bytes"`；P2 不過時 `files_differ` 列出每檔＋一句差在哪（例：「結尾換行」「key 順序」）。由隊長判斷是否屬無害差，若是，在 04 記「P2 退回 fable 的位元組只回報」並以 P1 為門。
