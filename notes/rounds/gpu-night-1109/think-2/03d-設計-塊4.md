## 1. 個體與檔案

個體＝一份 `tree.json`（`aos-tree/1`），`genome_sha = refs.genome_sha(defs, tree)` **每次寫檔重算**（存的值與重算值不符＝check FAIL）。

產物：`ws/evo/pop/g0/parent/{tree.json,quick/,fit.json}`、`ws/evo/pop/g1/<i>_<sha>/{tree.json,parents.json,check.json,quick/,fit.json}`、`ws/evo/pop/fit_cache.jsonl`、`ws/evo/pop/hall/`、`ws/evo/pop/g1/select.json`。

`parents.json`：`{"parents":[sha,…],"arm":"guided|uniform|clone|cross","ops":[{"op":"M1","path":"frozen.json/judge/stage2/se_mult","from":2,"to":3},…],"redraws":n}`。

## 2. 突變（`mutate.py`，`mutate(tree_doc, rng, guide) -> (tree_doc, record)`）

| 算子 | 對象 | 規則 |
|---|---|---|
| M1 參數抖動 | `frozen.judge.*` 數值、gate `payload.params.*`、route `payload.priority` | 值在 `bounds.json` 上下界內，int 走 ±1～±2、float 走 ×[0.7,1.3] 後夾界；bool 不抖 |
| M2 狀態翻轉 | 非 gate op 的 `status` live↔dormant | 只動 `status` |
| M3 刪 op | 非 gate、非唯一 decomp 的 op | 整列刪；樹內至少留 1 個 live comb |
| M5 節點權重 | `nodes/<k>/_metainfo.json.weight` | bounds `[0.25, 4.0]` |

**不可動欄位**（mutate 自身斷言＋check 再驗）：每列 op 的 `id`、`kind`、`born`、`by`、`sig`、`parent_route`、`payload.body`、`payload.src_tasks`；`truth/**`；`frozen.{holdout,taskset,budgets.L,budgets.epochs}`；`ctl`、`_view.sh`、`README.md`。

**引導臂（80%）**讀母樹的 `ws/evo/ledger/hammer/{retire_suggest.jsonl,credit.jsonl}`：
- `retire_suggest` 列中的 op（dormant-stale）→ 權重 ×4 當 M3 對象；`dormant-active` → M2 喚醒對象 ×2。
- op 的 credit 總額（layer 2 `to=ops/<id>` 加總）最高的 3 個 live op → M1 對象（若可抖）權重 ×2；最低者 → M2 休眠對象 ×2。
- 算子挑選比例：M1 0.4、M2 0.25、M3 0.25、M5 0.1。
**均勻臂（20%）**：算子與對象均勻亂抽。`arm` 由 `rng.random()<0.8` 決定並寫進 parents.json。

## 3. 交配（`crossover.py`，`cross(a_doc, b_doc, rng) -> (child_doc, record)`）

- X1 同 kind op 子集互換：對 a、b 共有 id 的 op，隨機選 ≥1 個以 b 的版本取代 a 的（同 id 的 `born/by` 兩邊必相同，不同就拒絕）；只在 b 有的 op 依 b 的列序插回（保列序，D12）。
- X3 `frozen.judge` 區塊整塊互換。
- 皆在**展開樹**上做，完成後 deduplicate、重算 sha。

## 4. check（`check.py`，`check(doc, parent_doc) -> {"ok":bool,"errors":[…]}`）

1. schema＝`aos-tree/1`；存的 `genome_sha` == 重算值。
2. 每個 `$ref` 指向存在的 `defs` 鍵；不留未用 defs（壞交配懸空 → FAIL `dangling_ref`）。
3. 不可動欄位（§2）與母代逐一比對：同 id 的 `born`、`by` 等改了 → FAIL `immutable:<id>.<field>`；不存在於任一親代的 op id → FAIL `alien_op`。
4. `bounds.json` 範圍內（route priority、judge、gate params、weight）。
5. import 到 scratch 目錄，`arcagi.hammer.check.check_root` 0 錯（`formats.check_op` 隨之全過）。
6. `guards.leak` 對子代：新 op（相對母代）`src_tasks ∩ (P∪H8∪H24) = ∅`；繼承的 tainted 照 D22 只回報。
7. 至少 1 個 live comb；gate op 存在且 live。
非法者在產生時重抽，每子代 ≤20 次；超過＝FAIL。

## 5. 適應度與選擇（`fitness.py`、`select.py`、`ga.py`）

- **F0**（免費）：check 結果、`n_live`、ops 數。
- **F1**：快撥 C25（`quick` 現有函式，`L=25000, epochs=4, threads≤4`，清 P），讀 `quick.json` 的 `auc_L, cost, eff, wall_s, per_task`。`fit_cache.jsonl` 命中就不跑。
- **對親代比較**：`noise.compare(parent_quick, child_quick)` 成對 bootstrap → `d_auc_L`、`sigma`、`z`；`significant = |z| ≥ 2`。同樹 σ=0 時記 `degenerate:true`、`significant:false`。
- **子樹適應度**：對子代快撥樹跑塊 3 credit（離線、epochs 1..4），第一層改**活動量版**：節點 k 在 epoch t 的權重 `a_k(t) = 1 + (k 持有的 live op 數) + (ledger.jsonl 該 epoch 歸 k 的列數)`；ledger 歸屬：`incubate→grow`、`promote/demote/retire→judge`、`epoch` 列不計。輸出 `credit_by_subtree`（守恆照塊 3）。
- **選擇**：(μ+λ)，候選＝親代＋8 子代，依 `eff` 排名（同 eff 取 `auc_L` 高、再取 sha 字典序）；菁英 2 直接留，其餘 μ−2=2 席用錦標賽 3（`seed` 固定）。μ=4。輸者**複製**到 `hall/`，不刪任何個體。寫 `select.json`。

1 代 8 子代組成（固定，讓每條路都走到）：5 突變（引導臂／均勻臂依 rng）、2 交配（取兩個不同突變子代，X1、X3 各 1）、1 **故意複製**（= 親代原檔 → `fit_cache` 命中）。

## 8. 已知限制

- M4、X2 不開（單親無外源料）；選擇只是管線，不保證變強。
- 快撥決定論 → 同樹 σ=0；子代與親代差 1 題時 z 約 1，難達顯著（Argon 11.2 已知）。
- 活動量版第一層的 ledger 歸屬表是代定（⚠推不出），op-less 節點只靠事件數區分。
