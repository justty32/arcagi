## 3. 輸入檔與欄位（實看樹，寫死）

樹根 `R` = CLI 第一個參數（今晚為 `/home/lorkhan/code/playground-arc1/ws/hammer`）。

**完成 epoch 的認定**：`R/epochs/<n>/` 中 `<n>` 為純數字且 `status.json` 存在者；`N` = 其中最大者（今晚 N=8，完成集合 = 0..8）。`--epoch N` 可指定，若該 epoch 未完成則報錯退出（exit 2）。

| 檔 | 實際格式 | 用到的欄位 |
|---|---|---|
| `R/ops.jsonl` | 每行一 op，21 行 | `id`, `kind`（gate/decomp/route/comb；無 sieve，但程式要容許 sieve）, `status`（live/dormant；容許 incubating）, `by`, `born` **＝ dict `{"by":…, "epoch": int}`**（Argon 說的 `born` 是對的，但它是 dict，取 `born["epoch"]`；不存在就當 0）, `mdl_bits`（gate/route/decomp 為 null）, `evidence` = `{"new_solves": [task_id…], "shadow_epochs": int, "witness_hits": int}`, `payload`（comb 有 `payload["name"]`，如 `g1_cd450dff4b`；op id = `"comb_" + name`） |
| `R/epochs/<e>/curve.csv` | **每個 epoch 一份、只有 1 列資料**（不是累積檔；Argon 這點說錯） | `epoch, solved_L, solved_H8, solved_H24, solved_P, logcost_L, lib_size, lib_bits, n_incubating, n_live, n_dormant, gate_in, promoted, rolled_back, stall, arm, evals_body, evals_shadow, evals_meta, evals_foundry, llm_calls, false_pos, env_hash, near_best_L, wall_s` |
| `R/epochs/<e>/solutions.jsonl` | 96 行（一題一行） | `task_id`, `set`（`L16`/`H8`/`H24`/`P`）, `train_ok`（bool；`program` 非 null ⇔ `train_ok`，已核 0..8 全成立）, `program`（seed AST；積木引用形式為 **`["blk", "<name>", 參數…]`**） |
| `R/epochs/<e>/blocks.json` | list of dict | 只用 `name`（主跑庫）。**注意：其中 `uses`、`idle` 欄引擎從未更新（全 0），不得使用** |
| `R/epochs/<e>/shadow_blocks.json` | 同上 | 只用 `name`（影子庫） |

不讀 `ledger.jsonl`、`frozen.json`、`live/`、`tmp/`、`nodes/`、`foundry/`。

**積木引用抽取**（兩支腳本共用邏輯，各自實作）：遞迴走 `program`，凡是 list 且長度 ≥ 2、`[0] == "blk"`、`[1]` 為 str，就把 `[1]` 收進集合。**不用字串 substring 比對**。

**貢獻（contrib）定義**：epoch e 中，comb 名 `name` 的 `contrib_L(e)` = `set=="L16"` 且 `train_ok` 且 `name ∈ 引用集合(program)` 的題數；`contrib_P(e)` 同理 `set=="P"`。**H8/H24 一律不讀進計分卡**（holdout 不餵審查，對齊簡報「驗證真值不餵升降」）。

## 4. `think1_audit.py`

**CLI**：`uv run python scripts/think1_audit.py <tree_root> [--epoch N]` → 寫 `<tree_root>/think1/audit/epoch-<N>.jsonl`，stdout 印一行 JSON：`{"epoch": N, "rows": 21, "verdicts": {...計數...}, "out": "<路徑>"}`。

**每列欄位（順序寫死，JSONL 一 op 一列，順序同 `ops.jsonl`）**：

| 欄 | 定義 |
|---|---|
| `id, kind, status, by, mdl_bits` | `ops.jsonl` 原樣 |
| `born_epoch` | `born["epoch"]`（缺則 0） |
| `age` | `N − born_epoch` |
| `shadow_epochs, witness_hits` | `evidence` 原樣 |
| `new_solves_n` | `len(evidence["new_solves"])` |
| `uses_L, uses_P` | 僅 `kind=="comb"`：`contrib_L(N)`、`contrib_P(N)`；其他 kind 為 `null` |
| `hit_rate_10` | 僅 comb：窗 W = 完成 epoch 中 `1 ≤ e ≤ N` 的最後 ≤10 個；`obs` = W 中 `name` 出現在 `blocks.json` 或 `shadow_blocks.json` 的 epoch；`hit` = obs 中 `contrib_L(e)+contrib_P(e) ≥ 1` 者；值 = `round(len(hit)/len(obs), 4)`，obs 空則 `null`。其他 kind `null` |
| `idle_epochs` | 僅 comb：`N − max{e ∈ [1,N] : contrib_L(e)+contrib_P(e) ≥ 1}`；從未貢獻則 `N − born_epoch`。其他 kind `null` |
| `verdict` | §4.1 階梯 |
| `rules_version` | `"a1"` |
| `note` | 字串；comb 固定寫 `"shadow-only epochs cannot contribute: solutions.jsonl is main-run only"`；非 comb 固定寫 `"no per-block trace for kind=<kind>; uses/hit/idle null"` |

### 4.1 verdict 階梯（嚴格 if-elif-else，照順序，無死角）

```
RULES = {"keep_hit_rate": 0.3, "retire_idle": 5, "stale_age": 6,
         "param_kinds": ("gate", "route", "sieve")}
uses = None if uses_L is None else uses_L + uses_P
ev_zero = (shadow_epochs == 0 and new_solves_n == 0 and witness_hits == 0)

P1 if status == "incubating":                      "incubating"
P2 elif kind in param_kinds and ev_zero:           "unmeasured"
P3 elif status == "dormant":
        "dormant-stale" if (age >= stale_age and new_solves_n == 0) else "dormant-active"
P4 elif status == "live":
        good = (new_solves_n >= 1) if uses is None
               else (uses >= 1 or (hit_rate_10 or 0) >= keep_hit_rate)
        idle = idle_epochs if idle_epochs is not None else age
        "keep" if good else ("retire-candidate" if idle >= retire_idle else "watch")
P5 else:                                           "unknown-status"
```

P2 排在 P4 前，所以 live 的 gate／route 證據全零時得 `unmeasured`（不會掉進 retire-candidate，修 Argon 衝突 1）；P3／P4 各有 else（修衝突 2）；P5 收未知 status。

## 5. `think1_meter.py`

**CLI 兩種模式**：
- `uv run python scripts/think1_meter.py <tree_root>` → 寫 `<tree_root>/think1/meta/curve-summary.json`，stdout 印同一份 JSON。
- `uv run python scripts/think1_meter.py --compare A.json B.json` → 只讀兩份 curve-summary，stdout 印一行 JSON（見下），不寫檔。

**curve-summary.json 欄位（寫死）**。記 `E` = 完成 epoch 集合（0..N），`S` = E 中 `e ≥ 1` 者，`c[e]` = `epochs/<e>/curve.csv` 那唯一一列：

| 欄 | 式 | 今晚期望 |
|---|---|---|
| `schema` | `"think1-curve/1"` | |
| `tree_root` | 絕對路徑字串 | |
| `epochs` | `len(E)` | 9 |
| `scored_epochs` | `len(S)` | 8 |
| `auc_L` | `Σ_{e∈S} solved_L` | **40** |
| `auc_P` | `Σ_{e∈S} solved_P` | **120** |
| `auc_H24` | `Σ_{e∈S} solved_H24` | **16** |
| `auc_H8` | `Σ_{e∈S} solved_H8` | **0** |
| `logcost_L_base` | `c[0].logcost_L` | 247.512 |
| `logcost_L_final` | `c[N].logcost_L` | 237.334 |
| `auc_speed_L` | `round(Σ_{e∈S} (logcost_L_base − c[e].logcost_L), 3)` | **43.539** |
| `cost` | `Σ_{e∈E} (evals_body+evals_shadow+evals_meta+evals_foundry)`（int） | **218157376** |
| `wall_s_total` | `round(Σ_{e∈E} wall_s, 2)` | 309.87 |
| `llm_calls` | `Σ_{e∈E} llm_calls` | **0** |
| `eff` | `round(auc_L / (cost/1e6), 4)` | **0.1834** |
| `lib_size_final, lib_bits_final, stall_final, arm_final` | `c[N]` 原樣（數字轉 int/float） | 3, 57.73, "stop", "rt_vsplit" |
| `per_epoch` | list，每 e∈E 一個 `{epoch, solved_L, solved_P, solved_H24, logcost_L, evals, wall_s, stall}`，`evals` = 四欄和 | 9 項 |

**`--compare A B` 輸出**：`{"d_auc_L": B−A, "d_auc_speed_L": B−A, "d_cost": B−A, "d_eff": B−A, "sigma_auc_L": <float|null>, "significant": <bool|null>}`。σ 來源：A 檔同目錄的 `noise.json` 的 `sigma_auc_L`；檔不存在 → `sigma_auc_L: null`、`significant: null`，並在 stderr 印 `WARN: noise.json missing; significance unknown`。存在時 `significant = abs(d_auc_L) > 2*sigma`。（noise.json 怎麼產生屬塊 B，今晚不做。）
