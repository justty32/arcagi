# GPU 遺傳符號搜尋（N3 gpgp）：白話結論（11-10 凌晨）

**像對五歲小孩講**：要猜出「把圖變成答案的咒語」。窮舉法是把所有短咒語從頭念一遍；遺傳法是先亂念一大堆，挑念得「比較像」的留下來互相拼湊、偶爾改一個字，一代一代越來越像。今晚比的是：同樣的時間，哪個方法找到的咒語比較多、比較長、比較快。

**結果一句話**：遺傳法沒贏。找到的題數和窮舉一樣多，速度比較慢，而且在真題上它找到的「答案」幾乎都是背答案、不是懂了規則。

**比賽怎麼比**：同一張顯卡、同一套積木（翻轉、縮放、鋪磚、換色……）、每題同樣秒數。題目有兩種：40 題主線一直沒解的真題，和 51 題人工埋進 5～7 步咒語的合成題（確認 3 步以內解不出）。另外放一個「亂念不挑」的對照組，看「挑選」有沒有用。

**題數打平**：合成題上，遺傳法和窮舉 test 答對的題數一模一樣（16、17、12）。挑選是有用的：不挑的對照組少對 2～4 題、慢好幾倍。

**「更深」是假象**：埋進去 7 步的題，窮舉其實都在 4～5 步找到等價的短咒語。遺傳法找到的咒語從來沒比窮舉短，有 16 題更長——那是多了沒用的廢字，不是看得更深。

**速度**：窮舉每秒試約 6000 萬支，遺傳法每秒約 90 萬支；解一題的中位時間窮舉 0.3～0.45 秒、遺傳法 0.6～0.9 秒。窮舉還能說「這個長度確定沒有解」，遺傳法說不出來。

**最大的警訊——背答案**：遺傳法說「解了」只代表練習題（train）都對。整夜跑的前 232 題它說解了 7 題，用 Python 拿考試題（test）重驗，**只有 1 題真的對**，另外 6 題都是拼出一長串剛好吻合 2～3 組練習題的咒語，考試就錯。像學生把練習卷答案背下來。

**下一步**：如果要把它當 aos「樹演化」的前身，評分不能只看練習題——要(1)留一組練習題當小考，背答案的過不了；(2)咒語越長扣越重（用「描述長度」計分）；(3)解出後強迫刪到不能再刪。更實際的分工：窮舉負責淺層，把高分的前幾步交給遺傳法往深處延伸。
