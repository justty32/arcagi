## 2. 不可違反的約束

| 約束 | 說明 |
|---|---|
| 成績以 **evaluation 400 題**為準 | training 有洩漏風險，只當開發集；**產生／評分積木只用 training** |
| 不用神經網路；**不新增 Python 依賴** | 純 stdlib。janet 1.41.2（`~/.local/bin/janet`，含 spork/json）是本機外部工具，可用子程序呼叫；不得讓求解器在 janet 不存在時壞掉（評測要能退回純 Python） |
| 機器安全 | `nice -n 19`、單批 ≤16GB、顯存 ≤12GB、swap 512MB；**全機同時一條全量評測**，開跑前 `pgrep -af "arcagi eval"` 確認沒人在跑；主線全量 `--workers ≤6`（另一半留給 aos 支線 S1／S2，已上線）；≤50 題子集隨時可跑 |
| 額度緊 | 約 **3 條 opus 線×1 小時**＋全量 training、evaluation 各一次 |
| 只讀 | aos repo、`~/repo/langs`（janet-lab、cl-lab）等參考庫 |
| 程式碼規矩 | `src/arcagi/<領域>/`，單檔 >300 行拆；pytest；退步列原因 |
| 支線路徑不碰 | `native/`、`src/arcagi/llm/`、`aos/llm/`、`objrule/families/`、`docs/taxonomy/`、`scripts/synth_*`… 留給 aos 支線（[支線.md](../支線.md)） |

## 3. 現況（r01～r04）

- 成績：**evaluation 37/400**（同大小 13/270）、training 92/400；退步 0；過 train 答錯 evaluation 13、training 24。
- 搜尋（`solvers/search.py`）：BFS 到深度 3、10 萬節點／20 秒、觀察等價去重、參數從範例推、最短程式勝出；終端學習器不佔深度。**預算不是瓶頸**（out_of_budget 0/400；深度 4 無增量）→ 要擴寬**參數候選**。
- 程式格式：`[[原語名, 參數…], …]`（`dsl/program.py`）；巨集 `aos/blocks/m_*/program.json`（4 個）；積木四型 `{"kind":pred|extract|formula|transform,"in","out","body"}`，body 是 S 式 JSON。`aos/blocks/` 365 個資料夾（extract 104、formula 125、pred 100、原語 ~30）。
- 產生器：`gen_predicates`、`gen_formula`、`gen_extract`，預算由帳 `generator_budget` 分（總額 25000 候選）；`_gen/_meta` 只調 **gen_formula**，分數＝training 可解釋題數 − 候選數/1000（**不是帳本分紅**），≤8 設定，層數封頂 2。
- 每物件規則（`objrule/`）：`recolor_from`／`move_from`／`extend_from`，參數來源＝物件視角抽取積木；只一步動作。
- 軌跡（`--traces`）每題記過 train 程式與**近失敗**（pixel_acc）：evaluation 未解 363 題中，近失敗 ≥0.9 有 **109** 題、≥0.95 有 46、≥0.98 有 10（training 102／45／9）。

## 4. 失分在哪

| 切片 | evaluation | 備註 |

| 同大小 | 13/270 | 每物件規則只一步；兩步（移動後補線）、斜向、依形狀定色未做 |

## 6. 要規劃者決定的方向問題

1. E1～E6 取哪些、怎麼分 3 條線（每條一個 opus、約 1 小時）。
2. 改寫搜尋的引擎放 **janet 內**（真的在原始碼空間跑，可讀、貼近使用者原意，但多一個子程序與跨語言除錯成本）還是 **Python 對同一 S 式**（快、好測；janet 只當表示與往返驗證）？或混合（janet 寫改寫規則表、Python 執行）。
3. `$ref` 折疊：用 aos `$ref` JSON 指示詞（與 aos 規範一致）還是 janet `defn`／巨集，或兩者都出（JSON 層 `$ref`、janet 層 `defn`）。
4. `_meta` 的分數：純帳本分紅（要等全量評測一個 epoch，慢且樣本少）vs 混合（便宜分數篩、分紅決定保留）；第 2 層要調什麼。
5. 驗收數字（隊長建議 evaluation ≥42、同大小 ≥18、training ≥100；過 train 答錯不增）。
6. 改寫搜尋的預算：每題多少秒／多少改寫候選；防背答案（改寫出的程式多題共用才加分？）。
