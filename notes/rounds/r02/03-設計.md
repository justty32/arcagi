## 1. 結論

照 fable：S4（top-2）→ S1 物件層 → S2 格線切塊 → S3 小 library learning＋A4 covered → A1 積木資料夾化 → A3 記帳 → A2 求解器資料夾程式；不碰 LLM。隊長改三處（記代定）：

- **「學習器類程式只能排第二」縮成只罰 `local_rule`**：換色表 `colormap` 是 r01 evaluation 10 題的主力，不能降級；過擬合主犯是鄰域規則表 → 有任何不含 `local_rule` 的解時它只排 top-2；只有它能解時照樣 top-1（D-r2-3）。
- **top-2 不改 eval 量具**：求解器把第二候選的 test 輸出放進軌跡 `metadata.second`，`scripts/score_top2.py` 從 eval 報告（含 expected）離線算 top-2（D-r2-4）。eval 與 compare 一行不動，r01 報告照樣能比。
- **registry 不「改成掃資料夾」**，而是「Python 實作總表 × 資料夾狀態過濾＋巨集」：沒有 `aos/blocks/` 時行為同 r01；有的話 `status=retired` 的原語不進搜尋、`kind=macro` 的資料夾變成新原語（D-r2-5）。資料夾掌身分與帳、Python 掌速度。

## 2. 模組與分線（同時 3 條，各寫各的檔）

| 線 | 模型 | 可寫 | 公開介面（隊長整合用） |
|---|---|---|---|
| L1 物件層 | opus | `src/arcagi/dsl/objects*.py`、`tests/dsl/test_objects.py` | `OBJECTS: dict[str, Primitive]`；`fit_object_colormap(states, targets, tests) -> table\|None`、`apply_object_colormap(grid, table)` |
| L2 格線＋top-2 | opus | `src/arcagi/dsl/cells.py`、`scripts/score_top2.py`、`tests/dsl/test_cells.py`、`tests/test_score_top2.py` | `CELLS: dict[str, Primitive]`；`score_top2(report) -> dict` |
| L3 aos 接入 | opus | `aos/`（repo 根）、`src/arcagi/blocks/`、`tests/blocks/` | `load_catalog(root) -> Catalog`（狀態、巨集程式）；`python -m arcagi.blocks.sync`／`.run`／`.pool`／`.library` |
| 隊長 | — | `dsl/registry.py`、`dsl/program.py`、`solvers/search.py`、notes、reports、ledger | 整合、跑全量、記帳 epoch 1 |

`Primitive` 介面沿用 r01：`Primitive(name, apply(grid, *params) -> Grid, candidates(states, targets) -> Iterable[params])`，`candidates` 只看 train 中間網格與目標，必須便宜（不適用時立刻回 `[]`）；參數必須 JSON 可序列化（int／str／list）。

## 3. S1 物件層（L1）

- 物件：`grid.objects` 四種切法（4／8 連通 × 同色／多色），背景＝眾數。屬性：`color`、`size`、`size_rank`（最大／最小）、`shape`（正規化後的格集合 id）、`touches_border`、`has_hole`、`shape_count`（同形物件數）、`h`、`w`。
- 選擇器＋動作原語：`recolor_sel(conn, attr, value, color)`、`delete_sel`、`keep_sel`、`fill_holes(color)`、`move_sel(dir)`（滑到邊或撞到）、`extend_sel(dir)`（從物件畫線到邊）。選擇器限**單一屬性述詞**（等於某值、最大、最小、唯一），由範例推：逐屬性檢查能否把 train 裡「有變」與「沒變」的物件完全分開，取最簡者；分不開就不產出。
- 終端學習器 `object_colormap`：物件屬性鍵 → 新顏色的表；每個鍵在 train 至少出現 2 次、test 物件鍵全在表內才產出（防背答案）。
- 只在同大小題進候選（`candidates` 先比尺寸）。

## 4. S2 格線切塊（L2）

- 只認整行／整列單色分隔線（可含外框）切出的等大小格。原語各自內部切格：`pick_cell(how)`（`unique`＝唯一跟其他不同、`most_colors`、`least_colors`、`has_color` 由範例推色）、`overlay_cells(op)`（and／or／xor 結果標記色 10，交給換色表）、`cells_to_pixels(mode)`（每格摘要成一像素：眾數非背景色／是否有物件）。等分無線格留第三輪。
- top-2：`score_top2(report)` 讀每題 `trace.metadata.second`（每個 test 一張網格或 null），任一嘗試全對就算對；輸出 `{tasks_correct_top1, tasks_correct_top2, newly_correct: [...]}`。

## 5. aos 接入（L3）

```
aos/blocks/<name>/_metainfo.json   # {name, kind: primitive|learner|macro, doc, params, cost, status: live|covered|retired, counter_uses}
aos/blocks/<name>/_entry           # sh：stdin {"grid":..., "params":[...]} → stdout 網格；呼叫 python -m arcagi.blocks.run <name>
aos/blocks/<macro>/program.json    # 巨集：純 JSON 程式（只含參數已定的步驟，不含學習器）
aos/solver/_entry                  # arcagi eval --external "aos-exec aos/solver {input} {output} {trace}"
aos/pool/{config.json,wallets.json,ledger.jsonl,epochs/<n>.json}
```

- `sync`：由 Python 總表產生／補齊 `aos/blocks/`（保留既有 status 與帳）。`run`：單一積木對一張網格（`aos-exec` 可叫）。
- `library`：讀 `--traces` JSONL，從過 train 程式抽出現 ≥3 次（不同題）的 2～3 步片段（去掉學習器、參數已定）→ 巨集資料夾；一個巨集解得出的題集若被更短程式完全涵蓋 → `status=covered`（想法 21，不刪）。
- `pool`（記帳，node-pool 簡化版）：一次全量 eval＝一個 epoch。收入＝解出題數×1000；頂層留 20%，80% 按解出題「選中程式」的積木靜態引用次數分紅；花費＝該積木本 epoch 被搜尋展開次數／1000×`cost`（預設 1）；房租 100／epoch；`balance` 累計；收入 0 則 `zero_streak+1`，≥3 列入 `epochs/<n>.json#/suggest_retire`（不自動退）。近失敗按引用積木追加 `_gradients.jsonl`。守恆：收入＝留存＋Σ分紅。epoch 0＝r01 evaluation 軌跡回放（無展開次數，花費記 0）。
- 搜尋要在軌跡 `metadata.block_calls` 記每個積木的展開次數（隊長加）。

## 6. 驗收（fable 數字，照抄）

- evaluation top-1 ≥30（目標 36），同大小切片 ≥10；top-2 另列。training ≥75（目標 90）；過 train 答錯 ≤15。每題 ≤10 秒（搜尋預算 5 秒）。
- pytest 全綠：物件屬性、選擇器推斷、格線切塊、top-2 計分、catalog 載入與過濾、帳本守恆。
- aos：(a) `echo … | aos-exec aos/blocks/flip_lr` 回網格；(b) `--external "aos-exec aos/solver …"` 20 題與 in-process 同分；(c) ledger 有 epoch 0、1，wallets 對帳；(d) 至少一個 S3 巨集資料夾，標 live 或 covered。

## 7. 子線限制（寫進任務書）

不 commit／push（隊長收）；不動別線與隊長的檔；不新增依賴；不跑 evaluation；training 子集 ≤100 題、`nice -n 19`；不讀寫 aos repo（只讀）；單檔 ≤300 行；回報＝改了哪些檔、pytest 結果、training 子集上的增量。
