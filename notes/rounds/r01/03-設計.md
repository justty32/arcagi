## 1. 結論

照 fable：純 Python、正式模組（`src/arcagi/dsl/`＋`src/arcagi/solvers/search.py`）、JSON 列表 S 式、逐層枚舉＋觀察等價＋尺寸剪枝、最短程式勝出、軌跡記全部過 train 的程式與近失敗。隊長加兩件（代定 D5、D6）：**終端學習器**（換色表、鄰域規則表）不佔深度、在每個節點上試擬合；**中間色 10 當標記色**，讓「填封閉區域」這類原語不用先猜顏色。

## 2. 模組與職責

| 檔 | 職責 | 公開介面 |
|---|---|---|
| `src/arcagi/dsl/grid.py` | 網格純函式：幾何、縮放、鋪磚、裁切、bbox、連通物件、背景色 | `flip_lr`、`rot90`、`upscale`、`objects`… |
| `src/arcagi/dsl/primitives.py` | 原語 registry：每筆＝名字、參數推斷函式、實作 | `PRIMITIVES: dict[str, Primitive]`；`Primitive.candidates(ctx)`、`Primitive.apply(grid, *params)` |
| `src/arcagi/dsl/learners.py` | 終端學習器：從（中間網格, 目標）配對學出表；衝突或 test 出現沒見過的鍵就放棄 | `fit_colormap`、`fit_local_rule` → 回傳可序列化的步驟或 None |
| `src/arcagi/dsl/program.py` | 程式表示：`Program = tuple[Step, ...]`，`Step = (name, *params)`；執行、JSON 往返、成本（MDL） | `run`、`to_json`、`from_json`、`cost` |
| `src/arcagi/solvers/search.py` | 搜尋與 plugin 入口：BFS、剪枝、選解、記軌跡 | `search(task, budget) -> SearchResult`；`solve(task) -> SolverResult` |

資料流：`SolverTask` → 狀態＝（每個 train 輸入、每個 test 輸入的目前網格）→ 每層對每個狀態試所有原語×推出的參數 → 新狀態的 **train 簽章**（所有 train 中間網格的 tuple）查重 → 簽章等於全部 train 輸出＝解；尺寸全對但顏色不對 → 試終端學習器 → 收集候選 → 選最短 → 套到 test 狀態 → 驗合法（0–9、≤30×30）→ 預測。

## 3. 原語（第一輪清單）

- 幾何（無參）：`flip_lr`、`flip_ud`、`transpose`、`rot90`、`rot180`、`rot270`、`anti_transpose`。
- 尺寸：`upscale(fy,fx)`、`downscale(fy,fx)`、`tile(ny,nx)` 參數由（目前網格尺寸, 目標尺寸）的整數比推，只在所有 train 比例一致時給；`mirror_tile(mode)`（2×1、1×2、2×2 鏡像拼接）；`crop_bbox`（背景＝眾數色）。
- 疊合：`split_overlay(axis, op)`：沿長或寬切兩半（中間若有一整條單色分隔線就跳過），兩半做 and／or／xor／nor，結果格寫 10（標記色），其餘寫 0，交給換色表定最終色。
- 物件：`crop_object(conn, select)`：conn ∈ {4 連通同色, 8 連通多色}；select ∈ {largest, smallest, unique_color, most_colors, top_left}；裁出該物件 bbox。
- 區域：`fill_enclosed`：背景格中不連通到邊界的塗成 10（D6）。
- 終端學習器（不算深度，成本各＋1）：`colormap(table)`：逐格「中間色→目標色」一對一表；`local_rule(features, table)`：同大小時「中心色＋4 鄰居色」→ 目標色（D5）。

## 4. 搜尋與預算

- 深度上限 3；每題時間預算 2.5 秒（`--timeout 10` 保險），節點上限 20000；到預算就停、用已找到的最短解。
- 尺寸剪枝：深度用盡前不剪（縮放可救）；最後一層只保留尺寸全對的節點才試學習器。
- 選解：`cost(program)`＝步數＋參數個數×0.1（學習出的表算 1 步）；同成本取先發現。過不了任何程式時回傳 test 輸入原樣（記 `selected=None`）。

## 5. 軌跡（接蒸餾）

`TraceRecorder` attempts：每個過 train 的程式（≤30 個）`kind="program"`、`program`＝JSON 字串；像素正確率最高的近失敗 ≤20 個 `kind="near_miss"`，`data.pixel_acc`；頂層 `metadata`＝題目特徵（尺寸關係、色數、新色數）、各深度節點數、是否逾預算。`--traces` 輸出的 JSONL 就是之後 library learning 的原料。

## 6. 量具與試驗場

- plugin：`arcagi.solvers.search:solve`，名稱 `dsl-search-r01`。
- 快驗：training 前 40 題（`--limit 40`）；全量兩次（training、evaluation 各一次）、`nice -n 19`＋`systemd-run --user --scope -p MemoryMax=16G`。
- 比較：`arcagi compare identity template dsl --labels docs/inventory/training-features.csv --label-column category`；報告 `reports/dsl-search-r01/README.md`，ledger 一列。
- 測試：`tests/dsl/`（原語性質、學習器衝突放棄、程式 JSON 往返）＋`tests/solvers/test_search.py`（合成題命中已知程式、軌跡合法）。

## 7. 能長大的接口

- 新原語＝registry 加一筆（不改搜尋）；C++／CUDA 版本照同一 JSON 程式格式重寫執行器，經 `--external` 接評測。
- LLM 入口（第二輪）：LLM 產 JSON 程式 → `program.run` 驗 train → 過的進軌跡；library learning 從軌跡抽高頻子序列註冊成巨集原語。
