## 1. 定稿

- **全盤採用 02**：步 0 做滿；步 1、4、5、6、7 最小可量版；步 2 只做格式與三投影殘差指紋；步 3（鍛造爐）、步 8 園區快取延 r10；守門搜尋不做（裁定 4）。五檔欄位照 02 §1.1，判準 M0～M5 照 02 §9（**看結果前寫死**，本檔 commit 時間即寫死時間）。
- Argon 8 問題＋4 提案的採納照 02 §3，逐條記代定 D-r9-3～D-r9-14。
- 隊長改動（代定 D-r9-15～）：
  1. 主樹名 `hammer`：decomp DEFAULT（C++ 七拆法）＋G1（經 `gate_g1` 列參數）＋loo 門＋P48＋ops 引擎；G4 關。對照 `dec-g1`（相容模式，M0）與 `hammer-frozen`（同設定，ops 引擎凍結：不升任何列＝不學對照，取代 r08 `pool-noG1`）。
  2. `halves`／`nest` 以 `decomp` 列（`by:agent-r08`、`incubating`）進表；它們需走 Python `seed.enum.solve`（S1 已證 0 差異），只在影子跑用。若被樹判升 live，04 要分開標「手寫拆法經樹判升」。
  3. 鑄模請求由隊長處理：daemon 在 epoch 邊界最多等 30 分；隊長每次最多派 1 個 opus 子 agent（裁定 1：一次 stop 一個蠟模）。本輪若 stall 沒判 stop，不硬鑄；改用 `ctl` 的「回放已記錄 stop」測試路徑驗通管線，並在 04 分開標（測試蠟模不計 M2(c)）。
  4. 所有曲線報告寫 `reports/curve-r09/<tree>/`，活樹本體在 `~/code/playground-arc1/ws/hammer/`；`reports/curve-r09/hammer/` 是收輪時從活樹 `epochs/` 拷出的快照（repo 內可追溯）。

## 2. 模組契約（`src/arcagi/hammer/`，純 stdlib，不 import 舊樹 dsl／solvers／objrule／blocks）

| 模組 | 職責 | 主要介面 |
|---|---|---|
| `formats.py` | 五檔讀寫與欄位檢查 | `load_ops(root)->list[dict]`、`append_ops`、`write_ops`（原子：寫 tmp 再 rename）、`append_ledger(root,row)`、`load_frozen`、`env_hash(ops)` |
| `check.py` | `python -m arcagi.hammer.check <root>` 五檔格式全檢 | 退出碼 0／1 |
| `body.py` | 本體：arcbatch 後端求解 | `solve_batch(tasks, lib_path, budget, cfg) -> list[dict]`，欄位同 r08 `curve.solve_task`；`backend="native"\|"python"` |
| `node.py`／`exec.py` | 節點資料夾、`_metainfo.json`、inbox 讀取；`python -m arcagi.hammer.exec <node>` stdin→stdout JSONL | `run(rows)->rows` |
| `epoch.py` | 一個 epoch 的 ①～⑦（02 §5） | `run_epoch(root, n) -> dict(row)` |
| `gate.py`、`grow.py`、`judge.py` | G1 門（參數來自 live `gate` 列）、反合一造 comb、兩段判準＋H24 回滾＋差集消融 | 沿用 `grow.compress`、`grow.pool` 函數（import 允許：`arcagi.grow`、`arcagi.seed`、`arcagi.tasks`） |
| `scan.py`、`sieve.py` | layer-2：gate 鄰域掃描、原語留一掃描、探針等價挖掘（只印） | `python -m arcagi.hammer.scan <root> --kind gate\|sieve` |
| `stall.py`、`route.py` | 停滯三判、UCB 四臂＋`parent_route` 分潤 | `judge_stall(ledger)->"ok\|starve\|saturate\|stop"` |
| `foundry.py` | 鑄模請求、蠟模解析、seed-sub 逐段擬合、斷裂面 | `request(root, task)`、`ingest(root, wax_path)` |
| `ctl.py` | 活樹指令（02 §6） | `python -m arcagi.hammer.ctl <cmd>` |
| `metrics.py` | ΔAUC_total、LTO-SCF∪ | 只報 |

- 腳本：`scripts/r09_hammer.py --tree dec-g1|hammer|hammer-frozen [--root DIR] [--epochs 8]`；`scripts/r09_taskset.py`（P48，`data/r09/taskset.json`）；`scripts/r09_report.py`。
- 測試：`tests/hammer/` 只放格式與相容性（M0）的幾支，跑一遍對就好。
