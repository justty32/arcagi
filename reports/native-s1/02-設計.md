支線 S1 第一輪設計：C++ 寬參數深搜尋 `arcsearch`＋Python 混合入口。

← [01 簡報](01-簡報.md)

## 1. 整體

```
native/bin/solve {input} {output} {trace}      (sh → .venv/bin/python native/hybrid.py)
  1. 照主線跑 arcagi.solvers.search.solve（同一份程式，保證退步 0）
  2. 主線 0 個過 train 程式 → 剩餘時間（19 秒 − 已用）呼叫 native/bin/arcsearch
  3. 每個 C++ 程式用 arcagi.dsl.program.run 在 train 重驗（在 task background context 下），
     不過的丟掉；test 輸出也用 Python 算
  4. arcagi.solvers.vote.choose 排序（同主線的懲罰與 shape hint）→ response＋trace
```

代定 S1-1：混合入口——主線有解就用主線答案，C++ 只補主線無解的題。理由：退步 0 是硬驗收，C++ 只移植部分原語（formula／extract／objrule 不移植），獨立跑必退步；Python 重驗讓「吐出的程式 Python 可執行且 train 全對」對**每一題**成立，而非抽 50 題。

## 2. C++ 引擎 `arcsearch`（native/src/，C++20、無外部依賴）

- 規格檔 `native/spec.json` 由 `native/export_spec.py` 從 `arcagi.dsl.registry` 產生：live 原語名、巨集展開、retired。C++ 只用 spec 裡 live 的名字。
- 網格：固定 30×30 uint8＋h,w；顏色 0–9 與 MARK=10。
- 移植（第一期）：`grid` 的 D4／縮放／tile、`primitives.BASE`、`primitives_more.MORE`、`cells`、learners `colormap`／`local_rule`、巨集。第二期：`objects`＋`object_colormap`。
- 搜尋：迭代加深 DFS，深度上限 5；每次迭代一張 transposition 表（train 網格 64-bit hash → 最淺深度）做觀察等價去重；每個新節點：train 全等→解；形狀全對→試 learner（colormap、local_rule n4／n8）。找到解的那一層走完就停。時間與節點雙預算。
- **寬參數**（關鍵）：每個原語的候選＝Python 推法（照抄）∪ 不看目標的寬集合：

| 原語 | 寬集合 |
|---|---|
| upscale／downscale／tile | (fy,fx) ∈ {1..4}²−(1,1)，結果 ≤30 |
| split_overlay | h／v × 5 op，只要能切 |
| crop_object | 2 conn × 5 how，不要求形狀變 |
| fill_enclosed、gravity×4、mirror_tile×3、self_tile×2 | 一律試 |
| symmetrize | 5 mode × 目前 train 出現的每個顏色 |
| cells 四個 | 版面存在就試全部 how／op／mode；has_color 試所有出現色 |
| colormap（中間步） | 單對 `[[a,b]]`，a ∈ 目前出現色（含 10），b ∈ 0..9 |

- 介面：`arcsearch --request R.json --budget S --max-depth D --out O.json`，O＝`{"solutions":[{"program":…,"cost":…}],"stats":{…}}`；`arcsearch --run` 讀 JSONL `{"program","grid","bg"}`、寫 `{"out"}`／`{"error":true}`，給 parity 測試用。
- 執行緒：每題單執行緒（評測 workers 並行題目，≤6）。

## 3. 測試（tests/native/）

- parity：從 training 題的網格抽樣，對每個移植原語×寬參數比 C++ `--run` 與 Python `program.run` 結果（含錯誤一致）。
- 端到端：幾題 training 小題經 `native/bin/solve` 解出。

## 4. 量法

- 子集（≤50 題）：主線 evaluation 未解題抽樣，看 C++ 補了幾題、每題秒數。
- 全量：照主線規則（pgrep 無人跑、workers 6、MemoryMax=8G、nice 19）。比較 `arcagi compare r04=artifacts/r04/dsl-evaluation.json s1=…`。
