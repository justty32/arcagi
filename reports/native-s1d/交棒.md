## 開發方式

- 用 `git worktree`（scratchpad 裡，branch `s1d`）。worktree 沒有 data 子模組：測試時在 worktree 的 `data/ARC-AGI` 放一個 symlink 指到 `~/repo/arcagi/data/ARC-AGI`；`git add` 之前要換回空資料夾，否則 git 會報 submodule 錯。
- 做完 rebase 到 main，在主 repo `git merge --ff-only s1d`，再 push。最後刪掉 worktree 和 branch。
