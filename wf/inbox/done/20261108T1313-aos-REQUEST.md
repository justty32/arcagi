# 使用者補充：aos 樹的子樹本身也是一種積木（併入第五輪主軸）

## 要你做什麼
使用者 11-08 午補充（原話，併入 12:56／13:09 的第五輪主軸）：「我們的aos樹本身，可能子樹也是一種積木」
頂層理解（參考）：不只單一資料夾程式是積木——aos 樹裡任何一棵子樹（一組節點連同呼叫關係，例如常一起出現的「抽取→公式→變換」組合，或一台產生器連同它產出的積木）都能整包當一塊積木：可被搜尋取用、可抽出重用（像巨集，但對象是子樹）、可記帳分紅、可被上層產生器改良。這跟「呼叫鏈當原始碼、$ref 折疊」是同一件事的兩面：子樹＝一段可 $ref 的原始碼。
