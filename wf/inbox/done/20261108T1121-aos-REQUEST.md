1. 環境補齊：照 README 跑 `scripts/setup_data.py`（下載兩個 submodule：ARC-AGI、re-arc——使用者要你開始準備，視為授權這次下載），再 `--check`、`pytest -q` 到全綠；identity 基線重跑一次 evaluation 留報告。
