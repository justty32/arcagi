# 實驗教學

從一份 JSON 設定比較不同語言、不同參數的解法，保留每次輸入／輸出與圖表。請在 repo 根目錄執行教學命令；設定檔內的相對路徑則以設定檔所在目錄為準。

- **還沒跑過** → [跑完第一個實驗](quickstart.md)：安裝、驗證、完整範例、單題和題型篩選。
- **要比較自己的方法** → [設定方法、參數與題型](configuration.md)：方法矩陣、tags、seed、重複次數。
- **要接 C++／Node／其他語言** → [檔案介面](protocol.md)：JSON 格式與 argv 範例。
- **要讀圖或分析資料** → [結果說明](results.md)：成功率、時間、CSV、原始紀錄和重現。
- **執行失敗** → [排錯](troubleshooting.md)：從輸出目錄、錯誤與 log 定位。

回 [使用教學總覽](../README.md)。
